FRESHER ASSESSMENT PROJECT
Full-Stack Mini Web Application Challenge

Objective

Evaluate the candidate's ability to:

●  Learn and apply new technologies quickly

●  Build a simple but complete full-stack web application

●  Package and run the app using Docker

●  Explain how their code and components work internally

Task Overview

●  Design & implement a simple web application with both frontend and backend.

●  Containerize the full system using Docker.

●  Explain the internal workflow and code logic (both architectural and runtime flow).

Problem Statements

1. Employee Leave Tracker

●  CRUD for employees, leaves, status (approved/pending).

●  Add a REST auth layer (JWT).

●  Frontend dashboards.

Technical Requirements

●  Frontend: Any modern framework.

●  Backend: Any language or framework.

●  Database: Optional — can use in-memory store, JSON file, SQLite, or any simple DB.

●  Containerization:

–  The app must run inside Docker containers (frontend + backend).
